AMANAH DELIVERY PWA — คู่มือเริ่มต้น (ภาษาไทย)

สิ่งที่มีในโปรเจกต์
- หน้าร้านและรายการสินค้า
- ตะกร้าและแบบฟอร์มสั่งซื้อ
- หน้าคำสั่งซื้อ
- หน้าสมัครไรเดอร์และจำลองรับงาน
- หน้าจัดการสินค้า/ส่งออกข้อมูล JSON
- PWA manifest และ service worker สำหรับติดตั้งบน Android

สำคัญมาก
โปรเจกต์นี้เป็นต้นแบบที่ใช้งานเดโมได้ โดยบันทึกข้อมูลใน localStorage ของเบราว์เซอร์เครื่องเดียว
ยังไม่ใช่ระบบ production: ลูกค้าและไรเดอร์คนละเครื่องจะไม่เห็นออเดอร์ร่วมกัน
ยังไม่มีบัญชีผู้ใช้/รหัสผ่าน, ฐานข้อมูลกลาง, การอนุมัติไรเดอร์, การชำระเงินออนไลน์, การแจ้งเตือน, แผนที่ติดตามสด หรือการคุ้มครองข้อมูลส่วนบุคคล
อย่าใช้เก็บข้อมูลลูกค้าจริงหรือเปิดรับออเดอร์สาธารณะจนกว่าจะเพิ่ม backend และระบบรักษาความปลอดภัย

วิธีใช้งานบน Android โดยไม่ใช้คอมพิวเตอร์
วิธีที่แนะนำ: ใช้ GitHub + Netlify ผ่าน Chrome
1. แตกไฟล์ ZIP ในแอปจัดการไฟล์ของมือถือ (ถ้าจะอัปโหลดทีละไฟล์) หรือเก็บ ZIP ไว้ก่อน
2. เปิด https://github.com แล้วสมัคร/เข้าสู่ระบบ
3. สร้าง repository ใหม่ชื่อ amanah-delivery ตั้งเป็น Public หรือ Private ตามความเหมาะสม
4. อัปโหลดไฟล์จากโฟลเดอร์โปรเจกต์ทั้งหมดไปที่ root ของ repository: index.html, manifest.json, sw.js, icon.svg
5. เปิด https://app.netlify.com แล้วสมัคร/เข้าสู่ระบบ
6. เลือกเพิ่มเว็บไซต์จาก Git repository (Add new project / Import an existing project) แล้วเลือก repository amanah-delivery
7. ตั้ง Build command ว่างไว้ และ Publish directory เป็น . หรือ root แล้ว Deploy
8. เมื่อ deploy สำเร็จ เปิด URL ที่ Netlify ให้มา ด้วย Chrome บน Android
9. แตะเมนู ⋮ ของ Chrome แล้วเลือก “ติดตั้งแอป” หรือ “เพิ่มลงในหน้าจอหลัก”
   (ข้อความในเมนูอาจต่างกันตามรุ่น Android/Chrome)

ทดสอบเดโม
1. เข้าเว็บที่ deploy
2. เพิ่มสินค้าในหน้าหลัก
3. ไปที่ตะกร้า กรอกชื่อ เบอร์โทร ที่อยู่ แล้วกดยืนยัน
4. ดูออเดอร์ในแท็บคำสั่งซื้อ
5. ไปแท็บไรเดอร์ สมัครไรเดอร์ แล้วทดลองรับงาน
6. แท็บจัดการร้านใช้เพิ่ม/ลบสินค้า และส่งออก JSON

ข้อควรทราบเกี่ยวกับเดโม
- ข้อมูลอยู่ในเบราว์เซอร์และอุปกรณ์นั้นเท่านั้น
- การรีเฟรชเว็บยังคงข้อมูลไว้บนเครื่องเดิม แต่การล้างข้อมูลเบราว์เซอร์อาจทำให้ข้อมูลหาย
- ไม่มีระบบผู้ดูแลที่ปลอดภัย จึงไม่ควรเผยแพร่ลิงก์เพื่อใช้งานจริงกับลูกค้าทั่วไป

ก่อนเปิดบริการจริง ควรเพิ่ม:
1. Backend/ฐานข้อมูลกลาง เช่น Supabase หรือ Firebase พร้อมกฎความปลอดภัย
2. ระบบสมัคร/เข้าสู่ระบบแยก ลูกค้า ร้านค้า ไรเดอร์ และผู้ดูแล
3. ขั้นตอนตรวจสอบเอกสารและอนุมัติไรเดอร์
4. ระบบจับคู่งานและป้องกันการรับงานซ้ำ
5. วิธีชำระเงินที่ยืนยันได้จริงและรายงานค่าจัดส่ง
6. การแจ้งเตือนสถานะ และแผนที่เมื่อมีความจำเป็น
7. นโยบายความเป็นส่วนตัว เงื่อนไขบริการ และช่องทางติดต่อ
